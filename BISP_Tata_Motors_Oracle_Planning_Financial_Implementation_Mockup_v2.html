Balance Sheet

Inventory = Opening + Production − COGS

Cash Flow

CFI = CapEx + Asset Sales

Closing Cash = Opening + CFO + CFI + CFF

Configure Attribute Dimensions

  1. Create the Product and Customer base dimensions.
  2. Create attribute dimensions such as Fuel Type, Brand, Region and Customer Tier.
  3. Define attribute members and aliases.
  4. Associate each attribute dimension with its base dimension.
  5. Assign attribute values to level-zero Product or Customer members.
  6. Refresh the database and validate attribute associations.
  7. Use attributes in forms, ad hoc analysis, reports and dashboards.
Design rule: Attribute dimensions are descriptive and should not be used as independent planning input dimensions.

Calculation Script

BR_Forecast_Seeding

FIX("Forecast","Working",&CurYr,@RELATIVE("All Entities",0)) FIX("Jan":"&ActualThrough") DATACOPY "Actual" TO "Forecast"; ENDFIX FIX("&FirstForecastMonth":"Dec") "Revenue" = "Vehicle_Volume" * "ASP" - "Dealer_Incentive"; "Material_Cost" = "Production_Units" * "Standard_Material_Cost"; ENDFIX ENDFIX

BR_DataCopy_Forecast

FIX(&Year,&PeriodRange,@RELATIVE(&Entity,0)) CLEARDATA "Submitted"; DATACOPY "Working" TO "Submitted"; ENDFIX /* Validate source/target POV and prevent copying into approved periods. */

BR_Calc_IncomeStatement

FIX("Forecast","Working",&CurYr,@RELATIVE("All Entities",0)) "Revenue" = "Sales_Volume" * "ASP" - "Dealer_Incentive"; "COGS" = "Material_Cost" + "Labor_Cost" + "Manufacturing_Overhead"; "Gross_Margin" = "Revenue" - "COGS"; "EBITDA" = "Gross_Margin" - "Operating_Expense"; "EBIT" = "EBITDA" - "Depreciation"; "Net_Income" = "Profit_Before_Tax" - "Tax_Expense"; ENDFIX

BR_Calc_BalanceSheet

FIX("Forecast","Working",&CurYr,@RELATIVE("All Entities",0)) "Accounts_Receivable" = "Opening_AR" + "Credit_Sales" - "Collections"; "Inventory" = "Opening_Inventory" + "Production_Cost" - "COGS"; "Accounts_Payable" = "Opening_AP" + "Purchases" - "Supplier_Payments"; "Net_PP&E" = "Opening_PP&E" + "CapEx" - "Depreciation" - "Asset_Disposals"; "Retained_Earnings" = "Opening_RE" + "Net_Income" - "Dividends"; ENDFIX

BR_Calc_CashFlow

FIX("Forecast","Working",&CurYr,@RELATIVE("All Entities",0)) "CFO" = "Net_Income" + "Depreciation" - "Change_in_AR" - "Change_in_Inventory" + "Change_in_AP"; "CFI" = - "CapEx" + "Asset_Sale_Proceeds"; "CFF" = "Debt_Drawdown" - "Debt_Repayment" + "Equity_Issued" - "Dividends"; "Closing_Cash" = "Opening_Cash" + "CFO" + "CFI" + "CFF"; ENDFIX

Configure Monthly Application Maintenance

  1. Create user variables for Current Year, Current Period and Forecast Start Month.
  2. Configure metadata refresh jobs for Account, Entity, Product, Customer and other custom dimensions.
  3. Create Data Integration jobs for Oracle Fusion Trial Balance, QuickBooks actuals and FX rates.
  4. Create forecast seeding and Data Copy business rules.
  5. Create a ruleset for Revenue, COGS, Workforce, P&L, Balance Sheet and Cash Flow.
  6. Configure Smart Push or Data Maps for the reporting cube.
  7. Create reconciliation reports and exception thresholds.
  8. Build a Pipeline to sequence jobs, stop on failure and send notifications.
  9. Schedule the Pipeline after source-system close and test restartability.
