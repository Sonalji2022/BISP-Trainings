1. Application identity

Create a distinct business process that can be managed, calculated and secured independently.

Required
Naming rule: letters, numbers and underscores; keep the name environment-safe.

2. Fiscal calendar

Define the time grain used for source data, drivers, calculations and reporting.

3. Currency and calculation precision

Control the financial unit, rounding behaviour and presentation of negative values.

4. Storage and dimensions

Establish the dimensional model that will hold financial, operational and allocation results.

5. Ownership and security

Assign accountability and establish the default access model for administrators and business users.

6. Select an application template

Choose an accelerator. The template seeds dimensions, model structure, sample drivers, reports and validation rules.
