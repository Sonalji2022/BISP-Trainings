How to Read These Statistics

Portal totals overlap

Do not add portal headline counts because the same vacancy can appear on several websites.

Skills are multi-valued

One job can request FCCS, ARCS, Data Integration and Groovy, so skill counts can exceed the number of jobs.

Use as a direction signal

The charts identify visible demand patterns; they are not a complete census of the Indian employment market.
