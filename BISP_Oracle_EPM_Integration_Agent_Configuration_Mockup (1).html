2. Download & Extract EPMAgent

Data Integration
Cloud EPM→ Data Exchange→ Data Integration→ Actions / Configure→ Download Agent
Contains agent executables and libraries, typically including the bin and lib folders.
Used for configuration, logs, scripts, and application-specific files.
powershell -Command "Expand-Archive EPMAgent.zip C:\EPM\EPMAgent"
Upgrade practice: keep application data separate from the agent binaries so upgrades do not overwrite configuration and logs.

3. Create Application Folders

File system

Run the application-folder utility before finalizing startup parameters. This creates an application-specific structure and populates the core home paths in the INI file.

7. Secure Authentication

Credentials

Password-based setup

Use the supplied encryption utility to write an encrypted Cloud EPM password reference. Do not place a production password directly in the HTML mockup or in shared documentation.

encryptpassword.bat "C:\EPM\EPMAgentData\Planning\config\agentparams.ini"

OAuth option

Prefer managed service accounts, least privilege, controlled secret rotation, and restricted access to the configuration directory.
