Security

Use dedicated integration users, least-privilege roles, secure credentials, certificate validation and controlled environment endpoints.

Control

Track file name, batch ID, source record count, target accepted count, rejected count, source total and target total.

Recovery

Use idempotent batch naming, retry-safe steps, archived source files, exception files and restart from the failed scope.

Configuration Sequence

Define the data contract
Ledger, accounting period, currency, balancing segment, account, cost center, movement and amount.
Create Fusion extract
Build BI Publisher data model/report or approved ERP extract with parameterized ledger and period.
Configure OIC connections
ERP Cloud Adapter, REST connection to EPM and optional SFTP or object storage connection.
Create EPM Data Integration objects
Source, target application, import format, location, period mapping, category mapping, data load mapping and rule.
Build orchestration
Schedule, extract, download, stage, map, validate, upload, invoke load rule and reconcile.
Operationalize
Monitoring, notifications, restart procedure, audit retention, UAT evidence and production support.

Common Errors and Solutions

ErrorLikely CauseResolutionPreventive Control
401 / 403 from EPMExpired password, incorrect URL, missing roleRetest REST connection, rotate credentials, validate EPM role and identity domainCredential expiry alert and service account governance
ERP report returns no rowsWrong ledger, period, access or report parameterRun BI Publisher manually with identical parameters and validate data securityParameter validation before orchestration
Invalid memberSource COA value has no target mappingAdd explicit/hierarchy mapping or correct metadataPre-load distinct-member validation
Period not mappedFusion calendar differs from EPM periodCorrect source period mapping and application calendarAnnual period-map review
File rejectedDelimiter, encoding, header or column order mismatchStandardize UTF-8 CSV and validate data contractSchema validation in OIC stage
Duplicate dataRetry reprocessed the same batchClear target slice or use replace mode and unique batch IDIdempotency key and batch ledger
Source/target totals differRounding, sign, currency, missing rows or mapping issueCompare totals by ledger, entity, account and currencyAutomated reconciliation thresholds
