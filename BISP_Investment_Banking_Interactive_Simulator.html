DCF Formula Walkthrough
PV(FCFₜ) = FCFₜ / (1 + WACC)ᵗ
Terminal Value = FCF₅ × (1 + g) / (WACC − g)
Enterprise Value = Sum of forecast-period PVs + PV of Terminal Value
Equity Value = Enterprise Value − Net Debt
Implied Share Value = Equity Value / Shares Outstanding

Accretion / Dilution Formula
Standalone EPS = Acquirer Net Income / Acquirer Shares
Pro Forma Net Income = Acquirer NI + Target NI + Synergies − Financing Cost
Pro Forma Shares = Acquirer Shares + New Shares Issued
Pro Forma EPS = Pro Forma Net Income / Pro Forma Shares
EPS Change % = (Pro Forma EPS / Standalone EPS − 1) × 100
